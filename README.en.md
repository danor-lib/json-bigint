# @danor-lib/json-bigint
![Version](https://img.shields.io/github/package-json/v/danor-lib/json-bigint?style=flat-square)
[![License](https://img.shields.io/github/license/danor-lib/json-bigint?style=flat-square)](https://www.gnu.org/licenses/lgpl-3.0-standalone.html)

A lightweight JSON parser and serializer with native `BigInt` support.

## Basic Example

````javascript
import { parse, stringify } from '@danor-lib/json-bigint';

const input = '{"big":9223372036854775807}';
const object = parse(input);

console.log(typeof object.big); // 'bigint'
console.log(object.big.toString()); // '9223372036854775807'

const output = stringify(object);
console.log(output); // '{"big":9223372036854775807}'
````

## Static Methods

### `parse(text, reviver?, option?)`

Parses a JSON string into a JavaScript value. This function automatically recognizes integers outside the safe integer range and converts them to `BigInt`.

- **Parameters**:
  - `text` `{string}` - The JSON text to parse.
  - `reviver` `{function}` `optional` - A transformer function identical to the native `JSON.parse` reviver.
  - `option` `{ParseOption}` `optional` - Parsing options.

`ParseOption` description
| Property              | Type                                | Default   | Description                                                                        |
| --------------------- | ----------------------------------- | --------- | ---------------------------------------------------------------------------------- |
| `preferParseAsBigInt` | `boolean`                           | `false`   | Prefer parsing numbers within the safe integer range as `BigInt`.                  |
| `preferBigIntString`  | `boolean`                           | `false`   | Return raw strings for numbers outside the safe integer range instead of `BigInt`. |
| `protoAction`         | `'error' \| 'ignore' \| 'preserve'` | `'error'` | Action to take when parsing an object key named `__proto__`.                       |
| `constructorAction`   | `'error' \| 'ignore' \| 'preserve'` | `'error'` | Action to take when parsing an object key named `constructor`.                     |

### `stringify(value, replacer?, space?)`

Serializes a JavaScript value into a JSON string. Supports `BigInt` type and preserves `toJSON`, `replacer`, and indentation options.

- **Parameters**:
  - `value` `{any}` - The value to serialize.
  - `replacer` `{function|Array}` `optional` - A replacer function or array identical to the native `JSON.stringify` replacer.
  - `space` `{string|number}` `optional` - Number of spaces or string to use for indentation.
